# 考研资料库 PWA 版本

## 📱 什么是PWA？

PWA（Progressive Web App，渐进式Web应用）是一种可以像原生APP一样使用的网页应用：
- ✅ 可以"添加到主屏幕"，像APP一样有图标
- ✅ 全屏运行，没有浏览器地址栏
- ✅ 支持离线使用（首次加载后缓存所有内容）
- ✅ 无需应用商店审核，无需安装包
- ✅ 跨平台：安卓、iOS、Windows、Mac都能用
- ✅ 自动更新，无需手动升级

## 🚀 快速开始（本地测试）

### 方法一：Python本地服务器（推荐）

```bash
cd pwa
python serve.py
```

然后浏览器会自动打开 `http://localhost:8080`

### 方法二：任何HTTP服务器

```bash
# Node.js
npx serve pwa

# PHP
php -S localhost:8080 -t pwa
```

> ⚠️ 注意：PWA功能（离线缓存、添加到桌面）需要通过HTTP服务器访问，直接双击打开HTML文件（file://协议）无法使用Service Worker。

## 📲 添加到手机桌面

### 安卓手机（Chrome浏览器）
1. 用Chrome打开网站
2. 点击右上角菜单（三个点）
3. 选择"添加到主屏幕"或"安装应用"
4. 确认后桌面会出现"考研资料库"图标
5. 点击图标即可全屏使用

### iPhone（Safari浏览器）
1. 用Safari打开网站
2. 点击底部分享按钮（方框+向上箭头）
3. 选择"添加到主屏幕"
4. 点击"添加"
5. 桌面出现图标，点击即可全屏使用

## 🌐 部署到线上（让任何人都能访问）

### 免费托管方案

#### 1. GitHub Pages（推荐，免费）
```bash
# 1. 创建GitHub仓库
# 2. 上传pwa文件夹所有内容
# 3. 仓库设置 → Pages → 选择main分支
# 4. 访问 https://你的用户名.github.io/仓库名/
```

#### 2. Vercel（免费，速度快）
```bash
# 1. 注册 vercel.com
# 2. 导入GitHub仓库
# 3. 自动部署，获得 https://项目名.vercel.app
```

#### 3. Netlify（免费，拖拽上传）
```bash
# 1. 注册 netlify.com
# 2. 直接把pwa文件夹拖到上传区域
# 3. 自动部署，获得随机域名
```

#### 4. Gitee Pages（国内访问快）
```bash
# 1. 注册 gitee.com
# 2. 上传pwa文件夹
# 3. 服务 → Gitee Pages → 启动
# 4. 访问 https://你的用户名.gitee.io/仓库名/
```

## 🔄 数据存储

所有学习数据（学习进度、错题本、复习记录、打卡记录）都保存在浏览器本地（localStorage），不会上传到任何服务器。清除浏览器数据会丢失记录，建议定期使用"导出数据"功能备份。

## ⚠️ 注意事项

1. **首次使用需要联网**：加载页面和pdf.js库（用于PDF挖空功能）
2. **离线使用**：首次加载后，Service Worker会缓存所有内容，之后可以离线使用
3. **PDF功能**：PDF挖空检测需要pdf.js库，首次使用时会从CDN加载
4. **iOS限制**：iOS上Safari的PWA支持部分功能，推送通知等不可用
5. **数据备份**：建议定期导出学习数据，避免清除缓存丢失

## 📞 常见问题

**Q: 为什么直接打开HTML没有PWA效果？**
A: Service Worker需要HTTP/HTTPS协议才能运行，file://协议不支持。请使用本地服务器或部署到线上。

**Q: 怎么更新到最新版本？**
A: PWA会自动检测更新，有新版本时会提示是否更新。也可以在设置中清除缓存后重新加载。

**Q: 数据会丢失吗？**
A: 数据保存在浏览器本地，只要不清除浏览器数据就不会丢失。建议定期导出备份。

**Q: 能在微信里打开吗？**
A: 可以在微信内置浏览器中打开使用，但"添加到桌面"功能需要用系统浏览器（Safari/Chrome）。
